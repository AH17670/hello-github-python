# Hello GitHub Python

这是我的第一个 GitHub 练习项目。

## 功能

输入名字，输出欢迎信息。

## 运行方式

确保已经安装 Python。

运行：

```bash
python main.py
```

## 示例

输入：

```text
张三
```

输出：

```text
你好，张三！这是我的第一个GitHub项目！
```

## 项目结构

```text
hello-github-python
├── main.py
└── README.md
```

## 学习目标

通过这个项目学习：

* Git 基础操作
* GitHub 项目发布流程
* README 文件编写
* VS Code 项目管理
